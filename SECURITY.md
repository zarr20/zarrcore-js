# Security Policy

This project follows the standard GitHub security policy. For vulnerability reporting, please see the [SECURITY.md](https://github.com/zarr20/zarrcore-js/blob/main/SECURITY.md) file.

- **Reporting vulnerabilities**: Open an issue with the label `security`.
- **Supported versions**: The latest stable release.
- **Security updates**: We use Dependabot to keep dependencies up‑to‑date.
