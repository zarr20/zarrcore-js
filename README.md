# zarrcore-js

Shared core utilities for modern TypeScript applications. Released under the MIT License.

## Installation

```bash
npm install zarrcore-js
```

---

## Features

## Features

- ⚡ Auto routing system
- 🌐 API handling utilities
- 📝 Form handling support
- 🛠️ Full TypeScript support
- 🧩 Modular and reusable architecture
- 🪶 Lightweight and framework agnostic
- 📦 Tree-shakable modules
- 🔄 ESM and CommonJS compatibility
- 🏗️ Scalable application structure
- ✨ Clean and maintainable developer experience
- 📄 MIT licensed

---

## Usage

```ts
import { example } from "zarrcore-js";

example();
```

---

## Development

Clone the repository:

```bash
git clone https://github.com/zarr20/zarrcore-js
```

Install dependencies:

```bash
npm install
```

Run development:

```bash
npm run dev
```

Build package:

```bash
npm run build
```
