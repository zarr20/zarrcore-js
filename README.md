```bash
npm install zarrcore-js
```

- 📝 Form handling support

## Development

Clone the repository:

```bash
git clone https://github.com/zarr20/zarrcore-js
```

Install dependencies:

```bash
npm install
```

Run development:

```bash
npm run dev
```

Build package:

```bash
npm run build
```
